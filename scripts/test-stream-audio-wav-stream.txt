This is a long streaming audio test for the wav-stream endpoint.

The goal is to verify that playback begins before the server finishes sending the full response body. If the player starts speaking while the network request is still active, then the backend is progressively streaming audio instead of buffering the complete file first.

To make this behavior easier to hear, this sample text is intentionally long. It contains several paragraphs and a mix of ordinary prose and technical language. That should give the text to speech pipeline enough time to produce multiple chunks of audio.
